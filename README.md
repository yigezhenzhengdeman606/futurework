# Future Atlas · AI Career Navigator

线上站点：[Futurework](https://futurework-career-navigator.snugkiwi16.chatgpt.site)，独立职业体验页：[体验大厅](https://futurework-career-navigator.snugkiwi16.chatgpt.site/experience)。当前已公开，无需登录 ChatGPT。网站访问时按间隔刷新研究信号；原每日定时任务仍需调整其私有访问检查。

托管版本位于 `deploy/futurework`，由 `node scripts/prepare-sites.mjs` 从现有源码准备，再在该目录运行 `node build.mjs` 生成无新增依赖的 Worker 产物。公开研究缓存保存在托管 R2 中，签名密钥通过 Sites secret 配置，不在源码中。`node --test` 包含 HTTPS、跨请求签名及独立体验的托管适配验证。托管站更新需按 Sites 的源码同步、打包及保存发布流程执行；本地修改不会自动上线。

帮助受 AI 影响的劳动者与未来人才探索职业转型：观察行业变化，识别可迁移技能，体验新职业的一天，再结合压力偏好匹配三个方向。职业与学习技能关联联合国 17 项可持续发展目标（SDG）。

## 本地运行

需要 Node.js 22 或更新版本，无需安装依赖。

```sh
npm start
```

打开 http://localhost:3000 。也可以直接运行 `node server.mjs`。用 `PORT` 环境变量调整端口；默认只监听本机。Replit 配置已更新为此入口。原 Python/RunPod 模板保留，但不是当前应用入口。

职业体验独立页面为 http://localhost:3000/experience ，首页和侧边栏均有入口，无需先填写档案。用户可直接选目录职业，也可输入具体岗位：AI 开启时先校验方向是否清晰，宽泛或有歧义的输入会返回补充问题，确认后才开启副本；关闭 AI 时支持通用规则体验并明确其局限。页面内部切换保留当前会话的 AI 配置，刷新仍会清除密钥。独立体验结束可查看复盘，再按需填写职业档案。

## 使用流程

1. **未来观察站**：七个行业的规则影响指数、可能减少的任务及新机会，展开查看来源与 SDG。指数是演示规则，不是失业概率。
2. **职业档案**：填写当前职业或学生专业、行业、已有技能、每周学习时间与关心的 SDG。
3. **职业方向与专属问题**：提交档案后，先选择是否希望从事专业相关工作。选择“是”后，基于专业、兴趣、行业和工作阶段填写三道专属问题；选择“否”直接生成转型建议与报告，取消专业相关加分并增加跨行业探索权重。专属回答参与排序和学习指导；报告提供三个职业方向、匹配原因、技能差距和学习路径，可下载 JSON。
4. **职业体验副本**：先显示职业人生封面，再自定上班、下班、洗漱、早餐、通勤、预留及就寝时间。进入黑底动画式的一天生活，大号时间转场后显示事件，覆盖起床到睡觉的 13 幕情境，包含三轮职业决策。闹钟倒推计算；多睡两分钟按游戏设定有 70% 概率睡过头并迟到，另外 30% 仅晚起两分钟。时间线随之改变。此概率不是真实统计，迟到不影响职业能力评分；体验结束填写职业喜好并进入压力测试。
5. **压力测试与匹配**：完成四项工作情境自评，将体验决策、精力、喜好和压力承受偏好纳入三个职业的重新排序。这不是心理健康诊断。
6. **可选 AI 设置**：选择 OpenAI 或 DeepSeek，填写模型和自己的 API Key。AI 覆盖行业趋势解读、档案分析、专属问题（含两道自由填写问题）、职业建议、学习路径、整日职业剧情、体验后的情境自评与再次匹配。报告会结合专属回答，从已支持职业目录中挑选并排序三个方向，分别生成理由和可检验的学习行动；规则分数、技能差距与 SDG 映射保留供参考。每日故事一次生成全部事件、工作选项和反馈，不逐幕调用。超时或结构不完整时明确回退完整规则流程；没有密钥时不调用模型。模型名以服务商当前支持列表为准。

## 每日数据更新

### 两种一天与场外角色

现在所有职业在开始前都可选择“正常的一天”或“困难的一天”。正常版本有 18 幕（3 次工作决策、3 次社交选择及后续），按时下班；困难版本有 22–24 幕（6 次工作决策、3 次社交选择及更多突发），90% 游戏概率加班 3 小时。中小学教师和医生仍默认困难模式、早上班，但允许选择正常版本。困难版本的加班时长为 3 小时。

父母会问候，许久未见的朋友与好朋友会邀约。用户可以报喜不报忧、坦白、另约时间，或在朋友与工作间选择。坦白与隐瞒有不同晚间对话；“全部都要”在普通／困难版分别有 35%／65% 游戏概率同时失误，造成待办压力、关系落差以及精力和心情下降，结果在选择时抽取一次，重绘页面不会重抽。晚间后续会根据已作出的选择变化。AI 个性化生成各事件、社交选项与成功／失败反馈；时间、概率和数值由规则保持一致。情绪数值是剧情反馈，不作心理诊断。日终复盘与后续 AI 推荐会收到社交选择记录。


服务器启动读取缓存，连接 arXiv AI 研究查询 API，使用研究标题作为技术信号。每分钟检查是否已满 24 小时，满足条件时抓取一次并重新计算行业指数；断网保留最近成功数据，页面显示失败状态、来源及更新时间。网页每分钟读取服务器最新快照。

**必须保持服务器运行，才能在关闭网页时继续每日更新。** 停机期间无法更新，重启后补抓。首次离线只显示规则基线。本版本没有实时招聘或劳动统计数据，研究信号不能直接推导岗位增减或准确就业预测。现有报告不会静默改写，重新提交资料可生成最新报告。

目标名称参考 [联合国 SDG 官方说明](https://sdgs.un.org/goals)，职业暴露概念参考 [ILO 2025 职业暴露研究](https://www.ilo.org/publications/generative-ai-and-jobs-refined-global-index-occupational-exposure)。角色和技能的目标关联是教学性映射，未经联合国认证；应用分数不是 ILO 官方分数。

## 隐私

动画后的 AI 接入引导和 AI 设置页面提供收费说明及一次体验费用申请入口，上限 CNY 1 元、以实际消费为准。用户选择微信、支付宝或 Touch ’n Go，上传收款码及消费凭证，生成本地 HTML 申请材料，再通过邮件发送到 `3473280583@qq.com`。邮件链接不能自动添加附件，用户需手动附加下载的文件；未配置邮件客户端时可以使用网页邮箱。上传图片不发送至服务器，不含 API 密钥。此功能不自动审核、转账或判定是否已申请；收件人需要人工核实消费金额与重复申请。关闭申请表会清除该表中的图片。

资料、API 密钥、体验和报告保存在页面内存中，刷新清除。服务端不持久保存用户资料或密钥，只在 `.cache/market.json` 缓存公开研究数据。主动下载的报告包含职业资料，不包含密钥。开启 AI 后，生成资料会发送至所选服务商，并可能产生费用；使用前请阅读界面说明。

仅支持两个固定 HTTPS API 端点，不支持任意代理 URL；没有登录、跨设备同步或多人数据库。

## 文件结构

```text

src/career.mjs         职业目录、行业估算、匹配、体验、自评

tests/career.test.mjs  Node 标准库自动测试

```

这是可运行的本地 MVP。未实现经真实就业数据校准的预测模型、完整游戏世界、执业资格评估、RunPod GPU 模型或公网部署。下一步应接入职业任务和招聘统计数据、评估预测误差，并扩充角色和情境。
