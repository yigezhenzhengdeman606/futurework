帮助受 AI 影响的劳动者与未来人才探索职业转型：观察行业变化，识别可迁移技能，体验新职业的一天，再结合压力偏好匹配三个方向。职业与学习技能关联联合国 17 项可持续发展目标（SDG）。

## 本地运行

需要 Node.js 22 或更新版本，无需安装依赖。

```sh
npm start
```

打开 http://localhost:3000 。也可以直接运行 `node server.mjs`。用 `PORT` 环境变量调整端口；默认只监听本机。Replit 配置已更新为此入口。原 Python/RunPod 模板保留，但不是当前应用入口。

职业体验独立页面为 http://localhost:3000/experience ，首页和侧边栏均有入口，无需先填写档案。用户可直接选目录职业，也可输入具体岗位：AI 开启时先校验方向是否清晰，宽泛或有歧义的输入会返回补充问题，确认后才开启副本；关闭 AI 时支持通用规则体验并明确其局限。页面内部切换保留当前会话的 AI 配置，刷新仍会清除密钥。独立体验结束可查看复盘，再按需填写职业档案。

## 使用流程

职业模拟已升级为情景实作：闹钟后先选择早餐、洗漱与出门检查，再处理已抽定的电器、资料和同事嘱托等突发。迟到由实际耗时计算，不再由赖床直接判定。迟到可能触发负责人沟通和错过会议，处理方式会持续影响待办、心情与精力。

当前界面中的三个主要工作阶段需要提交真实文字作品（初稿、调整、最终交付），不再使用职业任务三选一。八个内置职业有固定材料和四项评分标准；教学任务为课程设计，分析任务包含具体能耗数据，医生任务限定为协调与交接。困难模式增加约束和生活事件，仍保留三个主要作品阶段。自定义职业使用经澄清的岗位任务和通用交付框架，不声称覆盖完整职业技能。

最终交付可调用一次 AI 作品评阅：四项标准各0–4分，正分必须附上用户作答中实际存在的原文摘录，服务器验证数量、范围与引用；无 AI 或不合格响应只做结构检查，不编造专业分数。评分为模拟作品学习反馈，尚未进行职业效度验证。早晨迟到、饥饿和心情不直接扣作品分；新作品反馈不计作已验证的职业能力来加减匹配分。作品与反馈可下载 JSON。免费体验增加一个独立的作品反馈环节，仍受原有总名额、总预算和有限重试保护。

`POST /api/morning` 使用签名阶段记录推进 `wake`、`prepare`、`resolve`，`/api/day` 通过 `professional:true` 和 `morningToken` 构建新流程，`/api/task-assess` 接收签名任务及每阶段三项作答。旧版未带 `professional` 的日程接口保留兼容行为。

1. **未来观察站**：七个行业的规则影响指数、可能减少的任务及新机会，展开查看来源与 SDG。指数是演示规则，不是失业概率。
2. **职业档案**：填写当前职业或学生专业、行业、已有技能、每周学习时间与关心的 SDG。
3. **职业方向与专属问题**：提交档案后，先选择是否希望从事专业相关工作。选择“是”后，基于专业、兴趣、行业和工作阶段填写三道专属问题；选择“否”直接生成转型建议与报告，取消专业相关加分并增加跨行业探索权重。专属回答参与排序和学习指导；报告提供三个职业方向、匹配原因、技能差距和学习路径，可下载 JSON。
4. **职业体验副本**：封面之后自定作息，经过闹钟、准备与补救选择再进入整日生活。赖床可能睡过头，但是否迟到由实际耗时决定；忘带资料、同事嘱托、负责人沟通与错过会议会影响后续心情、精力和待办。三个主要工作阶段需要提交、修改和交付具体作品，最终以固定标准给出 AI 学习反馈或不编造专业分数的规则检查。
5. **工作情境偏好与匹配**：完成四项意愿选择，分别查看节奏变化、信息不确定、沟通协调和持续调整的回答。以四项均值作探索性摘要，按其与副本预设挑战强度的绝对距离扣分，并结合原有档案和体验喜好排序；不把意愿解释为抗压能力、职业能力或心理健康。结果逐职业展示预设强度与参考扣分。AI 只补充场景说明，不替换固定题目、选项或计分方向。
6. **可选 AI 设置**：选择 OpenAI 或 DeepSeek，填写模型和自己的 API Key。AI 覆盖行业趋势解读、档案分析、专属问题（含两道自由填写问题）、职业建议、学习路径、整日职业剧情、体验后的情境自评与再次匹配。报告会结合专属回答，从已支持职业目录中挑选并排序三个方向，分别生成理由和可检验的学习行动；规则分数、技能差距与 SDG 映射保留供参考。每日故事一次生成全部事件、工作选项和反馈，不逐幕调用。超时或结构不完整时明确回退完整规则流程；没有密钥时不调用模型。模型名以服务商当前支持列表为准。

## 每日数据更新

### 两种一天与场外角色

现在所有职业在开始前都可选择“正常的一天”或“困难的一天”。正常版本有 18 幕（3 次工作决策、3 次社交选择及后续），按时下班；困难版本有 22–24 幕（6 次工作决策、3 次社交选择及更多突发），90% 游戏概率加班 3 小时。中小学教师和医生仍默认困难模式、早上班，但允许选择正常版本。困难版本的加班时长为 3 小时。

父母会问候，许久未见的朋友与好朋友会邀约。用户可以报喜不报忧、坦白、另约时间，或在朋友与工作间选择。坦白与隐瞒有不同晚间对话；“全部都要”在普通／困难版分别有 35%／65% 游戏概率同时失误，造成待办压力、关系落差以及精力和心情下降，结果在选择时抽取一次，重绘页面不会重抽。晚间后续会根据已作出的选择变化。AI 个性化生成各事件、社交选项与成功／失败反馈；时间、概率和数值由规则保持一致。情绪数值是剧情反馈，不作心理诊断。日终复盘与后续 AI 推荐会收到社交选择记录。


服务器启动读取缓存，连接 arXiv AI 研究查询 API，使用研究标题作为技术信号。每分钟检查是否已满 24 小时，满足条件时抓取一次并重新计算行业指数；断网保留最近成功数据，页面显示失败状态、来源及更新时间。网页每分钟读取服务器最新快照。

**必须保持服务器运行，才能在关闭网页时继续每日更新。** 停机期间无法更新，重启后补抓。首次离线只显示规则基线。本版本没有实时招聘或劳动统计数据，研究信号不能直接推导岗位增减或准确就业预测。现有报告不会静默改写，重新提交资料可生成最新报告。

目标名称参考 [联合国 SDG 官方说明](https://sdgs.un.org/goals)，职业暴露概念参考 [ILO 2025 职业暴露研究](https://www.ilo.org/publications/generative-ai-and-jobs-refined-global-index-occupational-exposure)。角色和技能的目标关联是教学性映射，未经联合国认证；应用分数不是 ILO 官方分数。

## 隐私

动画后的 AI 接入引导和 AI 设置页面提供收费说明及一次体验费用申请入口，上限 CNY 1 元、以实际消费为准。用户选择微信、支付宝或 Touch ’n Go，上传收款码及消费凭证，生成本地 HTML 申请材料，再通过邮件发送到 `3473280583@qq.com`。邮件链接不能自动添加附件，用户需手动附加下载的文件；未配置邮件客户端时可以使用网页邮箱。上传图片不发送至服务器，不含 API 密钥。此功能不自动审核、转账或判定是否已申请；收件人需要人工核实消费金额与重复申请。关闭申请表会清除该表中的图片。

资料、API 密钥、体验和报告保存在页面内存中，刷新清除。服务端不持久保存用户资料或密钥，只在 `.cache/market.json` 缓存公开研究数据。主动下载的报告包含职业资料，不包含密钥。开启 AI 后，生成资料会发送至所选服务商，并可能产生费用；使用前请阅读界面说明。

仅支持两个固定 HTTPS API 端点，不支持任意代理 URL；没有登录、跨设备同步或多人数据库。

## 三语界面

自备 API 时必须选择密钥实际所属服务商；兼容协议不代表服务商密钥可混用。设置页切换服务商会同步模型默认名称。DeepSeek 的结构化与普通文本请求都明确关闭思考模式，以便短回答有可显示正文。服务端区分认证失败、余额/额度不足、模型或参数错误、限流、超时、空正文和连接故障；错误提示不回传服务商原始响应或密钥，不自动重试付费请求。失败时保留规则结果。

所有页面与弹窗提供中文、English、Bahasa Melayu 切换，浏览器保存语言偏好及不含服务商密钥的免费领取凭证。切换不会重建表单或重置体验进度；表单选项保留原始业务值，避免翻译改变匹配逻辑。界面、规则问题、报告、整日剧情、报销材料与错误提示使用随站打包的翻译，不依赖在线翻译服务，也不会发送用户输入进行翻译。

AI 请求携带当前语言，要求面向用户的生成内容使用该语言，保留结构字段、技能标识与签名。已经生成的自定义 AI 内容和用户原文保留生成时的语言，切换不会自动再次收费生成。英文、马来语术语校对位于 `public/locale-overrides.js`，基础文案位于 `public/translations.js`。

## 平台免费体验与报销

首批上限 15 个领取凭证，每个流程环节一次有效生成，失败最多手动重试一次。同一环节和资料的再次请求返回缓存；更改资料不能重复免费生成。免费流程包含一次资料解读、专属问题、报告、岗位澄清、一个职业的一天、一次作品评阅、自评题，以及一次再匹配或独立复盘。不包含行业 AI 解读或不限次数更换职业。

服务器秘密配置 `DEEPSEEK_API_KEY`、`SIGNING_KEY`（本地使用 `TRIAL_SIGNING_KEY`）和 `FREE_TRIAL_ENABLED=true` 后启用。`npm start` 读取忽略提交的 `.env.local`。平台密钥不下发客户端，不写入报销材料、用户结果或 GitHub。托管环境复用 R2，通过条件写入保护全局名额、在途调用预算与结果缓存；本地单进程使用 `.cache` 文件存储。

当前平台使用固定 `deepseek-flash` 非思考模式。预算为 2.25 元，单凭证最多 0.35 元，预留 0.25 元账户余量。调用前以输入 UTF-8 字节上界加消息封装余量和最大输出预留预算，按输入 2 元/百万 token、输出 8 元/百万 token 的高峰价格保守核算；成功时根据服务商用量调整，未知扣费的失败保留整笔预留成本。服务商调价后必须同步修改此价格假设。预算不足时保留规则结果，名额不保证无限次数或额外职业。

免费领取与报销二选一，生成报销材料前由服务器登记核验编号，领取者不能重复生成报销申请；报销登记者不能再领取免费名额。材料仍需发往 `3473280583@qq.com` 人工审核，最高实际消费 CNY 1，下载不等于提交或付款。

此版本按浏览器随机领取凭证识别，不是真实身份验证，无法完全阻止换设备、清除数据或多浏览器重复领取；全局名额和费用保护仍由服务器执行。严格限制每位自然人一次需要增加经验证的账号身份。免费体验的领取记录和生成结果保存在后台；个人 API Key 仍只保留在页面内存。

工作情境偏好使用 `work-context-v2`。四题 1–5 分取等权平均，参考调整为 `-3 × |偏好摘要 - 副本强度|`，范围 −12 至 0；其余匹配因素不变。不同答案组合可能得到相同均值，页面同时展示原始四项回答。副本强度是手工设定情境，不是职业调查数据，此规则尚未经过真实职业结果校准。`tolerance` 仅作为旧客户端兼容字段保留，不代表测得的抗压能力，新界面与排序均使用 `preferredIntensity`。免费用户修改偏好使用规则再匹配，不重复调用 AI；旧版缓存不可直接解释为新版问卷。
